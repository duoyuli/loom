# 分析索引

本页是 `wiki/analyses/` 的目录入口。分析页用于沉淀值得长期保留的回答、框架、对比、时间线、评审和备忘。

## 使用方式

- 所有分析页使用 `subtype` 标记类型。
- 当前固定小词表为 `framework / timeline / comparison / synthesis / review / memo`。
- 面向对象的深研默认按 [AGENTS.md](../../AGENTS.md) 中的横纵分析法协议拆成 `timeline / comparison / synthesis` 三类小页，而不是另建新的顶层目录。
