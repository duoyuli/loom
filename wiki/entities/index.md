# 实体索引

本页是 `wiki/entities/` 的目录入口。实体页用于承接人物、公司、地点、产品、项目、组织等稳定对象，并保存适合长期复用的对象判断。

## 当前状态

- 当前已收录 2 个实体页：
- [Hermes Agent](hermes-agent.md)：以真实 Agent 实现样本串起系统提示 anatomy、`Skills` 学习闭环、记忆边界与缓存约束。
- [OpenClaw](openclaw.md)：把文件驱动工作区、`Prompt / Context / Harness` 三层设计、双层 Memory 与 Hook 机制收束为对象页。
- 这里仍不预先展开空分类；只有真正跨来源、可复用的对象才新增页面。

## 何时新建实体页

- 当某个对象跨多个来源、问题或分析反复出现时。
- 当某个对象需要独立承接长期判断、关系网络或演化脉络时。
- 当把对象继续留在来源页或概念页里，已经会降低可检索性和可链接性时。

如果对象只在单一来源里短暂出现，优先保留在来源页、概念页或分析页中，不急于拆成实体页。

## 新页约定

- frontmatter 可选使用 `entity_type` 区分 `person / org / product / project / place`。
- 页面优先包含：摘要段、`## 纵向脉络`、`## 横向位置`、`## 当前判断`、`## 来源`，必要时补 `## 开放问题`。
- 如果围绕某个对象展开深研，实体页承接对象本身的长期判断，时间线、对比和综合判断优先放到 `wiki/analyses/`。
